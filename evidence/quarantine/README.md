# Quarantined Evidence

The evidence artifacts stored in this directory (`cp8-beta-readiness.json` and `cp9-sandbox-verification.json`) were quarantined per finding **F-TRUST-3**. These files originally contained hardcoded timestamps (`2026-11-01T00:00:00.000Z`) and literal `true` guardrail values derived from seeded fixtures rather than live measurement. They are retained here strictly for historical reference and must not be cited as empirical proof of readiness or security enforcement. Honest measurement and cohort verification are being rebuilt under UC0.2.
