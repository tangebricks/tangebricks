# Security Policy

## Supported versions

projectx-poc is pre-1.0. Only the `main` branch is supported; fixes land there and nowhere else.

| Version | Supported |
|---------|-----------|
| `main`  | Yes       |
| anything else | No  |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting:

https://github.com/tangebricks/tangebricks/security/advisories/new

Do not open a public issue, pull request or discussion for a suspected vulnerability.

Note: GitHub private vulnerability reporting only works on public repositories. This
repository is currently private, so the channel above opens when the repository is made public.

Please include what you found, how to reproduce it, and the impact you expect.

## What to expect

- We aim to acknowledge your report within 5 business days.
- We will keep you updated as we investigate, and tell you when a fix lands on `main`.
- We will credit you in the advisory unless you ask us not to.

## Scope

In scope: the code in this repository (the studio web app, studio API, bricks, packages,
scripts and GitHub Actions workflows).

Out of scope: third-party services and dependencies themselves (report those upstream),
denial of service through volume, and social engineering.

## Safe harbour

We will not pursue or support legal action against anyone who makes a good-faith effort to
follow this policy, avoids privacy violations and service disruption, and gives us reasonable
time to fix an issue before disclosing it.
